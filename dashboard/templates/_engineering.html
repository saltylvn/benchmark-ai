{#- Engineering and security controls, shown on the landing page and in Under the hood. -#}

Drafts only, two locks

Nothing has a send path for email or invoices. Slack posts need sending switched on and a named, signed-in approver.

Code computes, AI phrases

Dates, dollars and schedules are deterministic code. A guard rejects any AI rewrite that changes a fact.

Tested like it matters

151 automated tests, including 300 random-portfolio property tests. CI runs Node and Python 3.10 and 3.12.

Secure sign-in

Google and Slack OAuth with state checks, verified emails only, and an allowlist of who may sign in.

Hardened web app

Per-session CSRF tokens, strict content security policy, no framing, secure cookies, secrets only in the environment.

Signed integrations

Token-authenticated REST API. HMAC-signed webhooks with replay protection, retries and a delivery log.

Reliable by default

Atomic state writes, a schema-checked data contract, health checks, and a daily brief that never double-posts.

Deployed and automated

Render Blueprint with gunicorn, GitHub Actions for CI and the 8:00 brief, n8n templates for approvals.
